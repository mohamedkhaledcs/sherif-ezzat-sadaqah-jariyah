# صدقة جارية عن اخي شريف عزت رحمهٌ الله 

موقع تذكاري بسيط ومهيب؛ صدقة جارية لشريف عزت رحمه الله.

زوار الصفحة يقرؤون آيات وأدعية، يدعون له، ويمكنهم مشاركة الصفحة لتعم الفائدة.

## التشغيل

```bash
npm install
npm run dev
```

افتح [http://localhost:3000](http://localhost:3000).

## البناء

```bash
npm run build
npm start
```

## التقنيات

- Next.js (App Router) + TypeScript
- Tailwind CSS
- Lucide React
- PWA (`@ducanh2912/next-pwa`)
- بيانات محلية فقط (بدون قاعدة بيانات أو API)
